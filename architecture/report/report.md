**Версия:** 2.0 (Enterprise Target Architecture)  
**Дата:** 2 августа 2026 г.  
**Статус:** Утверждено  
**Группа разработки:** AI Architecture & Enterprise Integration Team  

---

## 1. Исполнительное Резюме (Executive Summary)

Платформа **Text2Business AI-Диспетчер** предназначена для автоматической интеллектуальной обработки входящих мультимедийных обращений (Telegram, Email, телефонные звонки, веб-формы, мессенджеры) от корпоративных заказчиков и B2B-клиентов.

Платформа решает следующие ключевые бизнес-задачи:
1. **Мгновенный извлекатель фактов (Zero-Delay Fact Extraction):** Извлечение структурированных данных (Заказчик, Объект/Сайт, Код оборудования/Актива, Описание проблемы, Желаемый дедлайн, Наличие резерва).
2. **Human-in-the-Loop (HITL) Консоль Диспетчера:** Автоматическое выявление недостающих фактов с подсветкой уверенности модели (Confidence Score).
3. **Бесшовная 1С:ERP / CRM Синхронизация:** Автоматическое проведение документов «ЗаявкаНаРемонт» и «ЗаказНаряд» по протоколу OData REST.

## 2. Целевая Событийная Архитектура (Target Architecture)

Платформа строится на базе событийно-ориентированной микросервисной архитектуры (Event-Driven Architecture, EDA):

```text
┌────────────────────────────────────────┐
│       ОМНИКАНАЛЬНЫЙ INGRESS GATEWAY    │
│        (Envoy Gateway)                 │
└──────────────────┬─────────────────────┘
                   │
                   ▼
┌────────────────────────────────────────┐
│   KAFKA / RABBITMQ EVENT BUS (EVENTS)  │
└──────┬──────────────────────┬──────────┘
       │                      │
   ┌───┴──────────────┐   ┌───┴─────────────────┐
   ▼                  │   ▼                     │
┌───────────────────┐ │ ┌───────────────────┐   │
│ SERVICE 1: STT    │ │ │ SERVICE 2: AI     │   │
│ (Yandex / Mochi)  │ │ │ (Python/LangGraph)│   │
└─────────┬─────────┘ │ └─────────┬─────────┘   │
          │           │           │             │
          └───────────┼───────────┘             │
                      ▼                         │
┌────────────────────────────────────────┐      │
│     SERVICE 3: CORE DECISION ENGINE    │◄─────┘
│        (Go / Temporal.io State)        │
└──────────────────┬─────────────────────┘
                   │
                   ▼
┌────────────────────────────────────────┐
│      DATA LAYER & OBSERVABILITY        │
│  • PostgreSQL 18 + pgvector + Redis    │
│  • Arize AI (OTel Metrics)             │
│  • 1C:ERP OData Enterprise Adapter     │
└────────────────────────────────────────┘
```

### Подробный разбор компонентов целевой схемы:

#### 1. Омниканальный Ingress Gateway (Envoy Gateway)
- **Функция:** Прием входящих HTTPS Webhooks (Telegram, Email Webhook, REST), gRPC соединений (Telephony RTP) и фильтрация трафика.
- **Безопасность:** TLS 1.3, Rate Limiting, защита от DDoS, валидация секретных токенов каналов.

#### 2. Event Bus (Apache Kafka / RabbitMQ)
- **Функция:** Декомпозиция входящего потока на асинхронные события (`InboundMessageReceived`, `AudioChunkStreamed`, `FactExtractionCompleted`, `TicketDispatchedTo1C`).
- **Преимущества:** Гарантированная доставка At-Least-Once, сглаживание пиковых нагрузок (Load Leveling).

#### 3. Service 1: Speech-to-Text & Telephony Engine (Yandex SpeechKit / Mochi)
- **Функция:** Потоковая транскрипция входящих телефонных вызовов в реальном времени.
- **Особенности:** Диаризация дикторов (Оператор / Клиент), удаление фоновых шумов, расстановка знаков препинания.

#### 4. Service 2: Perception & AI Engine (Python / LangGraph + vLLM / GitHub Models)
- **Функция:** Мультиагентное извлечение сущностей с валидацией по JSON Schema.
- **Поддерживаемые модели:** `gpt-4o`, `qwen3.6-27b`, `gemma4:e4b`, `deepseek-reasoner`, `nemotron-3-ultra-550b-a55b`.

#### 5. Service 3: Core Decision Engine (Go / Temporal.io State Machine)
- **Функция:** Оркестрация жизненного цикла заявки и гарантированное управление состоянием (State Machine).
- **HITL Интеграция:** При обнаружении недостающих критических полей (Confidence < 0.70) заявка переводится в состояние `WAITING_DISPATCHER`.

#### 6. Data Layer & Observability
- **PostgreSQL 18 + pgvector:** Реляционное хранение заявок, справочников активов и векторных эмбеддингов для RAG.
- **1C:ERP OData Enterprise Adapter:** Запись документов в 1С через стандартный интерфейс OData API.
- **Arize AI & OpenTelemetry:** Мониторинг полноты ответов нейросетей, дрейфа данных (Data Drift) и задержек (P99 Latency).

1. **Развертывание в Docker / Kubernetes:** Все компоненты упакованы в OCI-совместимые контейнеры.
