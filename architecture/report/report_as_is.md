# Технический Отчет: Текущая Архитектура (As-Is / MVP)

**Проект:** Text2Business AI-Диспетчер  
**Тип:** Монолитное Full-Stack приложение (Node.js/Express + React 19 SPA)  
**Дата:** 2 августа 2026 г.  

---

## 1. Назначение и Описание
Текущий прототип системы реализован в формате единого монолитного контейнера, объединяющего пользовательский веб-интерфейс Диспетчера, бэкенд обработчик вебхуков и детерминированный движок сопоставления с базой данных.

## 2. Состав Стекa
- **Runtime:** Node.js 20, TypeScript, Express.js.
- **Frontend:** React 19, Tailwind CSS, Lucide Icons, Vite.
- **Database:** In-Memory Object State (`mockDb.ts`).
- **AI Integration:** Direct REST HTTP requests to GitHub Models API / Gemini API с включенным JSON Mode (`response_format: { type: 'json_object' }`).
- **1C Integration:** Эмулятор OData REST API (`/api/1c/tickets`).

## 3. Ограничения Текущей Версии (As-Is)
1. **Синхронность:** Обработка обращения происходит синхронно в рамках HTTP-запроса от вебхука.
2. **In-Memory Store:** Данные сбрасываются при перезапуске сервера.
3. **Отсутствие шины событий:** Высокие сетевые задержки внешних нейросетей напрямую влияют на таймауты Telegram/Email вебхуков.
