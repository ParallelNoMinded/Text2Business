# ADR-003: Go / TypeScript Node.js Backend & Core State Machine

**Статус:** Принято  

## 1. Контекст
Выбор технологии для Core Decision Engine и HTTP Webhook Handler.

## 2. Решение
Для текущей рабочей системы используется Express/TypeScript на Node.js / Vite с готовностью перехода на Go + Temporal.io в рамках целевой архитектуры.
