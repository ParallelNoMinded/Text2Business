# ADR 001: Использование Structured Output (JSON Mode) для извлечения фактов

**Дата:** 2026-06-30  
**Статус:** Принято (Accepted)  

---

## Контекст
При обработке естественного языка (обращений клиентов) модель должна возвращать строго типизированную структуру данных с полями: `customer_name`, `site_info`, `asset_code`, `problem_summary`, `confidence`. Unstructured text приводит к сбоям интеграции.

## Решение
Использовать режим `response_format: { type: "json_object" }` (Structured Output) при обращении к GitHub Models API / Gemini API, либо детерминированную JSON схему в LangGraph агенте. В случае сбоя внешней нейросети применяется локальный регулярный/эвристический фаллбэк `extractFactsFromText()`.

## Последствия
- 100% валидный JSON на выходе.
- Исключение синтаксических ошибок парсинга в ядре диспетчеризации.
