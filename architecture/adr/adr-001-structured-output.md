# ADR-001: Стандартизация на Structured Output (GitHub Models / Gemini JSON Mode)

**Статус:** Принято  
**Дата:** 30 июня 2026 г.  

## 1. Контекст
AI-Диспетчер использует LLM (GitHub Models gpt-4o, qwen3.6-27b, gemma4:e4b, deepseek-reasoner, nemotron-3) для извлечения фактов (имя клиента, объект, код актива, суть проблемы, дедлайн, наличие бэкапа) из входящих сообщений. Текстовый вывод без схемы приводит к сбоям парсинга.

## 2. Решение
Форсировать вывод в строгом JSON формате через `response_format: { type: 'json_object' }` и предопределенные JSON schemas.

## 3. Последствия
- 100% валидность формата ответа.
- Прямой маппинг на интерфейс `ExtractedFacts`.
- Возможность автоматической проверки полноты данных для Human-in-the-Loop.
