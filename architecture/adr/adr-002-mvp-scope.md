# ADR-002: Границы MVP и Контур Интеграции 1С:Предприятие

**Статус:** Принято  
**Дата:** 30 июня 2026 г.  

## 1. Контекст
Необходимо было определить функциональные границы первой версии промышленного AI-Диспетчера.

## 2. Решение
В MVP включены:
1. Прием каналов: Telegram Webhook, Email, Telephony, REST API Dispatcher.
2. Автоматический извлекатель фактов с поддержкой GITHUB_MODELS_TOKEN (gpt-4o, qwen3.6-27b, gemma4:e4b, deepseek-reasoner, nemotron).
3. Интерактивная консоль Диспетчера (HITL) для ручного заполнения недостающих фактов.
4. Двусторонняя интеграция с 1С OData (`/api/1c/tickets`).
5. Инспектор реестра БД и логов/трейсов.
