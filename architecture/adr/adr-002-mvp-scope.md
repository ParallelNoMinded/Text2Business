# ADR 002: Границы MVP и контур интеграции с 1С:Предприятие (OData)

**Дата:** 2026-06-30  
**Статус:** Принято (Accepted)  

---

## Контекст
Необходимо определить объем функционала для рабочей первой версии (MVP) и интеграцию с корпоративными учетными системами 1С:ERP / 1С:УСЦ.

## Решение
1. MVP поддерживает входные каналы Telegram, Email, Голосовой ввод (Web Speech API / STT simulator) и Swagger REST API.
2. Взаимодействие с 1С реализуется через OData REST эндпоинты (`/api/1c/tickets`) для создания документа "ЗаявкаНаРемонт".
3. Предусмотреть Dry-Run режим, в котором заявки сохраняются в базе без реальной проводки в продуктивный контур 1С.

## Последствия
- Быстрое развертывание тестовых стендов.
- Безопасное тестирование без риска создания фантомных документов в 1С.
